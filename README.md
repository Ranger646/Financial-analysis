# 全球金融指标实时可视化工具

这是一个**轻量级单页仪表盘**，用于快速观察全球主要金融资产的实时变化，帮助你分析当前经济环境。

## 功能

- 一屏查看核心资产：
  - 美股/欧股/亚股主要指数
  - 主要汇率（EURUSD、USDJPY）
  - 大宗商品（黄金、原油）
  - 美国 10Y 国债收益率
  - 加密资产（BTC）
- 自动刷新（每 60 秒）+ 手动立即刷新
- 可切换互动图表（TradingView）进行细看

## 使用方式

1. 在仓库根目录启动静态服务器（任选其一）：

   ```bash
   python -m http.server 8080
   ```

2. 浏览器访问：

   ```
   http://localhost:8080
   ```

## 数据来源

- 行情卡片：Yahoo Finance Quote API
- 互动图表：TradingView Embed

> 说明：行情数据可用性与更新频率取决于数据源与网络环境。
